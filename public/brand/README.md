# Recursos de marca

`unibague-original.png` se descargó sin alteraciones de
https://pazyregion.unibague.edu.co/images/2019/02/12/2019-02-12-1.png
el 16 de octubre de 2026. Es la versión blanca que publica el sitio oficial;
se presenta sobre azul, con proporción intrínseca y espacio alrededor.

Los iconos existentes en `public/logos/web/` se conservan para PWA y favicon.
El archivo específico del conjunto gráfico completo de Paz y Región sigue
pendiente de entrega y aprobación por Comunicaciones. No se reconstruye.
La disponibilidad pública de un recurso no constituye aprobación para publicar
esta aplicación con identidad institucional.

Roboto procede de Google Fonts, versión servida v51. Los cuatro TTF se hospedan
localmente para evitar depender de una conexión externa durante el uso.
Licencia OFL 1.1 en `public/fonts/OFL.txt`.
